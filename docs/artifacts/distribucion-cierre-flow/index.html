💡 Punto Clave

El toggle "Asignar productos" al crear la distribución determina TODO el flujo posterior. Es puramente opcional y sirve solo para darle al admin la opción de llevar control de lo que entrega al vendedor vs lo que reporta al cerrar. No afecta el inventario del sistema en ningún caso.
