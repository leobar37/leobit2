Protecciones Internas

Cursor Atascado

Si el cursor no avanza y no hay cambios aplicados, el loop se rompe automaticamente:

nextSince === lastCursor && changesApplied === 0

Loop Protection

Maximo 1000 iteraciones por etapa para evitar loops infinitos:

MAX_ITERATIONS = 1000

Retry Tolerante (Historical)

Solo la etapa historica reintenta (3 veces) antes de fallar, con sleep entre reintentos:

if (batches < 3) { sleep(1000); continue; }
