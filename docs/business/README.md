## Convenciones para Agregar Nuevos Verticales

1. Crear un archivo `{nombre-vertical}.md` en esta carpeta
2. Seguir la estructura estandar (ver plantilla abajo)
3. Actualizar la tabla del README
4. Registrar hallazgos y peculiaridades en la seccion correspondiente

### Plantilla

```markdown
# [Nombre del Negocio]

## Resumen

## Flujo de Trabajo

## Entidades del Sistema

## Peculiaridades del Negocio

## Puntos de Venta / Modalidades

## Cobertura en Avileo

## Hallazgos Pendientes
```
