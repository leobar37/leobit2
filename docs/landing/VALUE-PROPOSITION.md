## 🎯 Primary Target: Avícolas (Poultry Businesses)

### Problem Statement
> "Tengo una avícola con varios vendedores. No tengo control de qué venden, quién debe, ni cuánto inventario asignar a cada uno. Cuando mis vendedores van a mercados sin internet, pierdo ventas."

### Solution Statement
> Avileo es el sistema de gestión de ventas offline-first diseñado específicamente para avícolas. Tus vendedores pueden vender sin internet, tú tienes visibilidad total de tu negocio.

---

### Value Propositions for Avícolas

| Pain Point | Avileo Solution | Benefit |
|------------|-----------------|---------|
| **Sin control de inventario** | Asignación diaria de kilos por vendedor | Sabes exactamente cuánto tiene cada vendedor |
| **No sé quién debe** | Seguimiento de cuentas por cobrar | Recupera tu dinero más rápido |
| **Internet inestable** | 100% offline | Nunca pierdes una venta |
| **Sin reportes** | Dashboard + Export Excel | Toma decisiones basadas en datos |
| **Vendedores en diferentes zonas** | Multi-vendedor con sync | Visibilidad centralizada |
| **Difícil cobrar deudas** | Sistema de abonos + historial | Seguimiento fácil de pagos |
| **Perder comprobantes** | Comprobantes por WhatsApp | Cliente tiene su recibo siempre |

---

### Customer Profile: Avícola

```
Industry:     Poultry / Chicken Sales
Company Size: 2-20 employees
Role:         Owner / Administrator
Pain:         No visibility, lost sales, manual processes
Tech Level:   Low - just wants it to work
```
