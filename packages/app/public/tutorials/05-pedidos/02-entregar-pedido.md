# Entregar un pedido

Cuando llega la fecha acordada, debes **entregar** el pedido al cliente. Este proceso convierte el pedido en una venta completa.

## ¿Cuándo entregar un pedido?

Entrega el pedido cuando:

- Llega la fecha de entrega acordada
- El producto está listo y disponible
- El cliente está presente o listo para recibir

## Cómo entregar un pedido

### Paso 1: Buscar el pedido

1. Ve a la pestaña **Pedidos**
2. Busca en la lista o usa el buscador
3. Los pedidos de hoy aparecen destacados

> 💡 **Tip**: Puedes filtrar por **"Confirmados"** para ver solo los listos para entregar.

### Paso 2: Abrir el pedido

Toca el pedido para ver sus detalles:

- Cliente
- Productos solicitados
- Fecha de entrega
- Anticipo registrado (si aplica)

### Paso 3: Verificar productos

Antes de entregar:

1. Revisa que tengas todos los productos
2. Verifica cantidades y calidad
3. Si hay diferencias, ajústalas:
   - Toca el producto
   - Modifica la cantidad real entregada
   - Agrega nota explicando el cambio

### Paso 4: Ajustar precios (si es necesario)

Si los precios cambiaron desde que se hizo el pedido:

1. Revisa los precios mostrados
2. Puedes mantener el precio cotizado o actualizar al precio actual
3. El sistema calcula el nuevo total

> 💡 **Tip**: Para clientes fijos, es buena práctica respetar el precio cotizado original.

### Paso 5: Definir forma de pago

Elige cómo pagará el cliente:

### Opción A: Contado

1. Selecciona **"Contado"**
2. Elige método de pago (efectivo, Yape, etc.)
3. Si hay anticipo, se descuenta automáticamente
4. Ingresa el monto recibido
5. El sistema calcula el vuelto (si aplica)

### Opción B: Crédito

1. Selecciona **"Crédito"**
2. El anticipo (si existe) se aplica a la deuda
3. El resto queda como deuda del cliente
4. Opcional: establece fecha de vencimiento

### Opción C: Anticipo ya cubre todo

Si el anticipo fue mayor o igual al total:

1. El sistema detecta automáticamente
2. La venta queda como **"Pagada"**
3. El excedente (si existe) queda a favor del cliente

### Paso 6: Confirmar entrega

1. Revisa el resumen final:
   - Productos entregados
   - Precios aplicados
   - Total a pagar
   - Forma de pago
   - Anticipo aplicado

2. Toca **"Confirmar entrega"**

3. El sistema:
   - Crea la venta correspondiente
   - Descuenta del inventario
   - Actualiza el estado a **"Entregado"**
   - Genera comprobante

## Después de la entrega

### Comprobante

Al igual que las ventas normales, puedes:

- Compartir por WhatsApp
- Imprimir (si tienes impresora)
- Solo guardar

### En el historial del cliente

La entrega aparece como:
- Una venta más en su historial
- Con nota indicando que vino de un pedido

## Casos especiales

### Cliente no puede recibir

Si el cliente no está disponible:

1. **Reprogramar**: Edita el pedido y cambia la fecha
2. **Dejar con tercero**: Registra quién recibe con nombre y DNI
3. **Cancelar**: Si el cliente ya no lo quiere

### Producto no disponible

Si no puedes cumplir con el pedido completo:

1. Comunícate con el cliente
2. Ofrece alternativas o cantidades parciales
3. Ajusta el pedido antes de entregar
4. Si no hay acuerdo, cancela el pedido

### Cambios de último momento

El cliente quiere agregar más productos:

1. Durante la entrega, puedes agregar productos
2. O crea una venta nueva aparte
3. El pedido original se entrega como estaba

## Diferencias entre pedido y venta final

El sistema guarda un registro de:

| Aspecto | Pedido original | Venta final |
|---------|----------------|-------------|
| Productos | Lo solicitado | Lo realmente entregado |
| Precios | Cotizados | Aplicados |
| Cantidades | Estimadas | Reales |
| Total | Estimado | Final |

Esto permite analizar qué tan precisos son tus pedidos vs. las entregas reales.
