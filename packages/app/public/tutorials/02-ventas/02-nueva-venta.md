# Cómo hacer una venta

Este tutorial te guía paso a paso para registrar una venta en Avileo.

## Paso 1: Iniciar una nueva venta

Hay dos formas de iniciar:

### Opción A: Desde el Dashboard
1. Toca el botón naranja **+** (flotante)
2. Selecciona **"Nueva venta"**

### Opción B: Desde la sección Ventas
1. Ve a la pestaña **Ventas**
2. Toca el botón **"Nueva venta"**

## Paso 2: Seleccionar el cliente

> ⚠️ **Importante**: Para ventas al crédito, el cliente DEBE estar registrado.

### Si el cliente ya existe:
1. Toca el campo **"Buscar cliente"**
2. Escribe el nombre o número de teléfono
3. Selecciona el cliente de la lista

### Si el cliente es nuevo:
1. Toca **"+ Nuevo cliente"**
2. Completa los datos:
   - Nombre completo (obligatorio)
   - Teléfono (opcional pero recomendado)
   - Dirección (opcional)
3. Toca **"Guardar"**
4. El cliente se selecciona automáticamente

### Venta sin cliente (solo contado):
- Puedes dejar el cliente vacío para ventas rápidas al contado
- Esto es útil para clientes ocasionales que pagan de inmediato

## Paso 3: Seleccionar productos

1. Toca **"Agregar producto"**
2. Selecciona el **producto** del catálogo
3. Selecciona la **variante** (tamaño/tipo)
4. Ingresa la **cantidad** o **peso**

### Si usas la calculadora (venta por peso):
1. Toca el icono de **calculadora** 🧮
2. Ingresa el **peso bruto** (con empaque)
3. Selecciona o ingresa la **tara** (peso del empaque)
4. El sistema calcula el peso neto automáticamente
5. Toca **"Agregar al carrito"**

### Repite para más productos
Puedes agregar varios productos a la misma venta. Cada uno aparecerá en el carrito.

## Paso 4: Revisar el carrito

En la sección **Carrito** verás:

| Columna | Descripción |
|---------|-------------|
| Producto | Nombre y variante |
| Cantidad | Unidades o kilos |
| Precio unit. | Precio por unidad/kg |
| Subtotal | Cantidad × Precio |

Para eliminar un producto:
- Desliza el item hacia la izquierda
- Toca **"Eliminar"**

Para modificar cantidad:
- Toca el item
- Cambia la cantidad
- Toca **"Actualizar"**

## Paso 5: Seleccionar modo de pago

### Venta al contado:
1. Selecciona **"Contado"**
2. Elige el método de pago:
   - 💵 Efectivo
   - 📱 Yape
   - 📱 Plin
   - 🏦 Transferencia
3. Ingresa el **monto recibido** (para efectivo)
4. El sistema calcula el **vuelto** automáticamente

### Venta al crédito:
1. Selecciona **"Crédito"**
2. Verifica que el cliente esté seleccionado
3. Opcional: ingresa una **fecha de vencimiento** estimada
4. El sistema registra la deuda automáticamente

## Paso 6: Confirmar la venta

1. Revisa el **resumen**:
   - Subtotal
   - Total
   - Método de pago
   - Cliente

2. Si todo está correcto, toca **"Confirmar venta"**

3. Verás una **confirmación** con los detalles de la venta

## Paso 7: Imprimir o compartir (opcional)

Después de confirmar:

- **Imprimir**: Si tienes impresora térmica conectada
- **Compartir**: Envia el comprobante por WhatsApp
- **Guardar**: Solo guarda la venta sin compartir

> 💡 **Tip**: Puedes configurar la impresora en Configuración > Impresora.

## Ejemplo completo

**Escenario**: Cliente habitual "María García" compra 2.5 kg de pollo entero y paga con Yape.

1. ✅ Nueva venta
2. ✅ Buscar "María García" y seleccionarla
3. ✅ Agregar producto:
   - Producto: Pollo
   - Variante: Entero
   - Usar calculadora: Tara 0.05 kg, Peso bruto 2.55 kg → Neto 2.5 kg
4. ✅ Carrito muestra: Pollo Entero 2.5 kg × S/ 15.00 = S/ 37.50
5. ✅ Modo: Contado, Método: Yape
6. ✅ Confirmar venta
7. ✅ Compartir comprobante por WhatsApp

## Si cometes un error

Si necesitas **anular una venta**:

1. Ve a la lista de ventas
2. Busca la venta
3. Toca y mantén (o usa el menú)
4. Selecciona **"Anular"**
5. Confirma la anulación

> ⚠️ **Importante**: Solo los administradores pueden anular ventas. Las ventas anuladas se registran en el historial.
