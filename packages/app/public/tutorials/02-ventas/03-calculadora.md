# Uso de la calculadora

La **calculadora de pollo** es una herramienta esencial para vendedores que trabajan con productos vendidos por peso. Te ayuda a calcular el peso neto restando el empaque.

## ¿Qué es la tara?

La **tara** es el peso del empaque o recipiente que contiene el producto. Para cobrar correctamente, debes restar este peso del peso total.

| Elemento | Descripción | Ejemplo |
|----------|-------------|---------|
| **Peso bruto** | Producto + empaque | 2.550 kg |
| **Tara** | Peso del empaque | 0.050 kg |
| **Peso neto** | Producto solo | 2.500 kg |

## Cómo usar la calculadora

### Paso 1: Acceder a la calculadora

Hay dos formas:

1. **Durante una venta**: Toca el icono 🧮 al agregar un producto
2. **Desde el menú**: Algunos usuarios tienen acceso directo

### Paso 2: Ingresar el peso bruto

1. Coloca el producto en la balanza
2. Lee el peso en la balanza (ejemplo: 2.55 kg)
3. Ingresa este valor en **"Peso bruto"**

### Paso 3: Seleccionar o ingresar la tara

Avileo tiene taras predefinidas para empaques comunes:

| Empaque | Tara típica |
|---------|-------------|
| Bolsa plástica pequeña | 0.01 kg |
| Bolsa plástica mediana | 0.02 kg |
| Bolsa plástica grande | 0.05 kg |
| Bandeja de poliestireno | 0.03 kg |
| Caja de cartón pequeña | 0.10 kg |

#### Si la tara está en la lista:
1. Selecciona el tipo de empaque
2. La tara se completa automáticamente

#### Si necesitas tara personalizada:
1. Selecciona **"Otra"** o **"Personalizada"**
2. Pesa el empaque vacío
3. Ingresa el valor manualmente

### Paso 4: Obtener el resultado

La calculadora muestra automáticamente:

```
Peso bruto:    2.550 kg
Tara:         -0.050 kg
              ---------
Peso neto:     2.500 kg

Precio/kg:    S/ 15.00
Total:        S/ 37.50
```

### Paso 5: Agregar al carrito

Toca **"Agregar al carrito"** y el producto se añade con el peso neto calculado.

## Ejemplos prácticos

### Ejemplo 1: Pollo entero en bolsa

- Peso en balanza: 3.20 kg
- Bolsa grande: 0.05 kg
- **Peso neto: 3.15 kg**
- Precio: S/ 15.00/kg
- **Total: S/ 47.25**

### Ejemplo 2: Menudencia en bandeja

- Peso en balanza: 1.85 kg
- Bandeja: 0.03 kg
- **Peso neto: 1.82 kg**
- Precio: S/ 12.00/kg
- **Total: S/ 21.84**

### Ejemplo 3: Medio pollo sin empaque

- Peso en balanza: 1.50 kg
- Sin empaque: 0.00 kg
- **Peso neto: 1.50 kg**
- Precio: S/ 16.00/kg
- **Total: S/ 24.00**

## Consejos útiles

> 💡 **Tip 1**: Siempre pesa el empaque vacío al inicio del día para verificar la tara.

> 💡 **Tip 2**: Para ventas grandes, puedes usar la calculadora múltiples veces y sumar los productos.

> 💡 **Tip 3**: Si tu balanza tiene función de tara, puedes restarla directamente en la balanza y usar ese valor como peso neto.

## Errores comunes

| Error | Solución |
|-------|----------|
| Olvidar restar la tara | Siempre verifica que el peso neto sea menor que el bruto |
| Tara incorrecta | Selecciona el empaque correcto de la lista |
| Confundir gramos con kilos | La calculadora usa kilos (ej: 50g = 0.05kg) |

## Configurar taras personalizadas

Si usas empaques especiales frecuentemente, pide al administrador que agregue la tara al sistema:

1. Administrador va a Configuración > Productos
2. Selecciona "Gestionar taras"
3. Agrega nueva tara con nombre y peso
4. Estará disponible para todos los vendedores
