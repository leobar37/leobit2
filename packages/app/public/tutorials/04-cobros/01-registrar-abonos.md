# Registrar un abono

Un **abono** es un pago parcial que hace un cliente para reducir su deuda. Este tutorial te explica cómo registrar estos pagos en Avileo.

## ¿Qué es un abono?

Cuando un cliente te debe dinero por una venta al crédito, puede ir pagando poco a poco. Cada pago parcial se registra como un **abono**.

### Ejemplo

- Deuda total: S/ 500
- Abono 1: S/ 200 → Deuda restante: S/ 300
- Abono 2: S/ 150 → Deuda restante: S/ 150
- Abono 3: S/ 150 → Deuda saldada: S/ 0

## Cuándo registrar un abono

Registra un abono cuando:

- El cliente te paga parte de lo que debe
- El cliente te paga la deuda completa
- Recibes un pago por Yape, Plin o transferencia
- El cliente paga en efectivo

## Cómo registrar un abono

### Paso 1: Acceder al formulario

Hay dos formas de iniciar:

**Opción A: Desde Cobros**
1. Ve a la pestaña **Cobros**
2. Toca el botón **"Nuevo cobro"** o **+**

**Opción B: Desde el cliente**
1. Ve a **Clientes** y busca al cliente
2. Toca el botón **"Registrar abono"**

### Paso 2: Seleccionar cliente

1. Busca el cliente en el campo de búsqueda
2. Selecciona el cliente de la lista
3. Verás automáticamente:
   - Deuda actual del cliente
   - Historial de abonos recientes

### Paso 3: Ingresar el monto

1. Escribe el **monto recibido**
2. El sistema muestra:
   - Deuda antes del abono
   - Deuda después del abono
   - Si cubre la deuda completa o es parcial

> 💡 **Tip**: Si el cliente paga la deuda completa, el sistema lo detecta automáticamente y marca la deuda como saldada.

### Paso 4: Seleccionar método de pago

Elige cómo te pagó el cliente:

| Método | Información adicional |
|--------|----------------------|
| **Efectivo** | Sin información extra |
| **Yape** | Número de operación + foto del comprobante |
| **Plin** | Número de operación + foto del comprobante |
| **Transferencia** | Número de operación + banco |

### Paso 5: Agregar comprobante (opcional pero recomendado)

Para pagos digitales, puedes adjuntar una foto:

1. Toca **"Agregar comprobante"**
2. Toma una foto o selecciona de la galería
3. La imagen se guarda con el abono

> ⚠️ **Importante**: Los comprobantes ayudan a resolver disputas. Siempre guarda evidencia de pagos digitales.

### Paso 6: Confirmar

1. Revisa el resumen:
   - Cliente
   - Monto del abono
   - Método de pago
   - Deuda restante

2. Toca **"Confirmar abono"**

3. Verás confirmación y el nuevo saldo del cliente

## Después de registrar el abono

### El sistema actualiza automáticamente:

- ✅ Saldo del cliente (reduce la deuda)
- ✅ Historial de abonos del cliente
- ✅ Reporte de cuentas por cobrar
- ✅ Estadísticas de cobranza

### Puedes:

- Compartir el recibo por WhatsApp
- Imprimir el comprobante (si tienes impresora)
- Ver el historial actualizado del cliente

## Abonos parciales vs totales

### Abono parcial

Cuando el cliente paga parte de la deuda:

- El cliente sigue apareciendo en la lista de deudores
- La deuda restante sigue activa
- Puedes seguir registrando más abonos

### Abono total (liquidación)

Cuando el cliente paga todo lo que debe:

- El cliente desaparece de la lista de deudores
- La deuda se marca como "Saldada"
- Todas las ventas asociadas quedan pagadas

## Errores comunes

| Error | Solución |
|-------|----------|
| Monto mayor a la deuda | El sistema alerta. Verifica el monto o registra el excedente como "a favor" |
| Cliente incorrecto | Cancela y vuelve a iniciar con el cliente correcto |
| Método de pago equivocado | Edita el abono inmediatamente después de crearlo |

## Corregir un abono

Si te equivocaste al registrar:

1. Ve al **historial del cliente**
2. Busca el abono incorrecto
3. Toca y mantén (o usa el menú)
4. Selecciona **"Editar"** o **"Eliminar"**

> ⚠️ **Importante**: Solo puedes editar abonos del día actual. Abonos antiguos requieren ajuste por administrador.

## Trabajar offline

Puedes registrar abonos sin internet:

1. El abono se guarda localmente
2. Se sincroniza cuando hay conexión
3. El saldo del cliente se actualiza localmente de inmediato
