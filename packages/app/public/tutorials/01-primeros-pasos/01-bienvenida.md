# Bienvenida a Avileo

¡Hola! Bienvenido a **Avileo** (también conocido como PollosPro), el sistema diseñado para ayudarte a gestionar tu negocio de venta de pollos de manera eficiente, ya sea que trabajes desde tu local o recorriendo las calles con tu carrito.

## ¿Qué es Avileo?

Avileo es un **sistema de gestión de ventas offline-first** pensado especialmente para:

- **Vendedores ambulantes** de pollos y productos avícolas
- **Negocios de venta al por mayor y menor**
- **Emprendedores** que necesitan controlar sus ventas, clientes e inventario

## Principales beneficios

### 🌐 Funciona sin internet
El sistema está diseñado para trabajar **100% offline**. Puedes registrar ventas, clientes y cobros incluso cuando no tengas conexión. Los datos se sincronizan automáticamente cuando recuperas la señal.

### 📱 Diseño móvil primero
Avileo está optimizado para funcionar en celulares, con una interfaz táctil y fácil de usar mientras atiendes a tus clientes.

### 💰 Control de créditos
Lleva el control de quién te debe y cuánto. Registra abonos fácilmente y consulta el historial de deudas de cada cliente.

### 📊 Reportes en tiempo real
Visualiza tus ventas del día, cuentas por cobrar y el desempeño de tu negocio desde cualquier lugar.

### 👥 Multi-usuario
Tu negocio puede tener varios vendedores. Como administrador, puedes invitar a tu equipo y asignarles productos para vender.

## ¿Para quién es este sistema?

| Perfil | Cómo te ayuda |
|--------|---------------|
| **Vendedor ambulante** | Registra ventas rápidamente, incluso sin internet. Consulta precios y stock. |
| **Administrador** | Gestiona el inventario, asigna productos a vendedores, revisa reportes. |
| **Negocio familiar** | Controla quién vende qué, cuánto se vendió y quién debe pagar. |

## Tu primer inicio de sesión

Para comenzar a usar Avileo necesitas:

1. Una cuenta de usuario (email y contraseña)
2. Pertenecer a un negocio (puedes crear uno o ser invitado)
3. Tu rol asignado (administrador o vendedor)

> 💡 **Tip**: Si eres el dueño del negocio, crea tu cuenta y luego invita a tus vendedores desde la sección de Equipo.

## Estructura del sistema

El sistema está organizado en módulos principales:

- **Ventas** - Registra ventas al contado y al crédito
- **Clientes** - Gestiona tu base de clientes
- **Cobros** - Registra pagos y abonos
- **Pedidos** - Administra pedidos para entrega futura
- **Productos** - Catálogo e inventario (solo admin)
- **Distribuciones** - Asigna stock a vendedores
- **Cierre** - Resumen diario de ventas
