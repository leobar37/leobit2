# Iniciar sesión y registro

Para acceder a Avileo necesitas una cuenta de usuario. Este tutorial te explica cómo crear una cuenta nueva o iniciar sesión si ya tienes una.

## Crear una cuenta nueva

Si es la primera vez que usas Avileo:

1. En la pantalla de inicio, toca **"Crear cuenta"**
2. Ingresa tu **nombre completo**
3. Ingresa tu **correo electrónico** (debe ser válido)
4. Crea una **contraseña segura** (mínimo 8 caracteres)
5. Toca **"Registrarse"**

> ⚠️ **Importante**: Debes tener conexión a internet para crear tu cuenta. Una vez creada, puedes trabajar offline.

## Iniciar sesión

Si ya tienes una cuenta:

1. Ingresa tu **correo electrónico**
2. Ingresa tu **contraseña**
3. Toca **"Iniciar sesión"**

### ¿Olvidaste tu contraseña?

Si no recuerdas tu contraseña, contacta al administrador de tu negocio para que te ayude a restablecerla.

## Después de iniciar sesión

Una vez dentro del sistema, verás el **Dashboard** o la pantalla principal. Desde aquí puedes acceder a todas las funcionalidades usando el menú de navegación.

### Seleccionar un negocio

Si perteneces a varios negocios (por ejemplo, eres vendedor en más de uno), el sistema te pedirá que selecciones con cuál quieres trabajar.

## Invitaciones de equipo

Si eres vendedor, probablemente recibiste una **invitación** por email para unirte a un negocio existente:

1. Abre el email de invitación
2. Toca el enlace o copia el código de invitación
3. Si ya tienes cuenta, inicia sesión
4. Si no tienes cuenta, créala primero
5. La invitación se aceptará automáticamente

> 💡 **Tip**: Las invitaciones expiran después de 7 días. Si tu invitación venció, pide al administrador que te envíe una nueva.

## Cerrar sesión

Para cerrar sesión:

1. Ve a tu **perfil** (icono en la esquina superior)
2. Selecciona **"Cerrar sesión"**

> ⚠️ **Importante**: Asegúrate de sincronizar tus datos antes de cerrar sesión en un dispositivo que usará otro vendedor.

## Seguridad de tu cuenta

- Nunca compartas tu contraseña
- Usa una contraseña única para Avileo
- Si sospechas que alguien tiene acceso a tu cuenta, cambia tu contraseña inmediatamente
